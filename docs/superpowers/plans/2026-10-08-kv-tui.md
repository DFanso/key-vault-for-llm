# kv TUI and approvals Implementation Plan (Plan 4 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `kv tui`: approve `mode: ask` requests as they arrive (replacing the immediate `approval_timeout`), add, edit and remove handles and their policies, lock the vault and read the audit log, all from one terminal UI that unlocks once with a control session token.

**Architecture:** The daemon gains control sessions (a token traded for the passphrase once) and an approval queue. An agent request that needs approval is decided under the daemon lock but waits outside it on a oneshot channel, so other requests keep flowing; the TUI polls `overview` and answers with `decide`. The TUI is split into a pure state machine (`app`: keys in, effects out, outcomes applied), a renderer (`view`), and a `Driver` that alone talks to the daemon and holds the token, so nearly everything is tested without a terminal.

**Tech Stack:** Rust 2024 (MSRV 1.89), ratatui 0.30 (crossterm through `ratatui::crossterm`), notify-rust 4.18, tokio 1.53; tests use ratatui's `TestBackend` and wiremock 0.6.

**Spec:** `docs/superpowers/specs/2026-10-08-kv-llm-secrets-broker-design.md`. This plan implements section 2's control session token and agent sessions, step 3 of section 4's request pipeline, and section 5's Unlock (TUI), Approval (TUI) and audit viewing. Task 5 updates the spec where the implementation settled details it left open.

## Global Constraints

- `rust-version = "1.89"`, edition 2024.
- New dependencies are limited to `ratatui = "0.30"` and `notify-rust = "4.18"`. Use crossterm through `ratatui::crossterm`, not as a direct dependency.
- No agent-socket message may carry a secret value; `Hello` carries only a session id and a self-reported client name.
- The session token is 256 random bits, lives only in daemon and TUI memory, is compared in constant time, and never appears in `Debug` output, the audit log or a reply other than `Session`.
- The passphrase and secret values typed into the TUI are kept in zeroizing buffers and never drawn.
- The daemon's mutex is never held while a request waits for approval.
- Agent-supplied text is made safe before the TUI draws it: control characters replaced, length capped.
- All failures are closed: an unanswered request is `approval_timeout`, a denied one `approval_denied`, and one waiting when the vault locks `vault_locked`; none of them ever runs.
- Commits: author `DFanso <leogavin123@outlook.com>`, no AI attribution lines or `Co-Authored-By` trailers.
- **On this Mac**, prefix cargo commands with `DEVELOPER_DIR=/Library/Developer/CommandLineTools` (the Xcode license is not accepted). The commands below include it; drop it elsewhere and in CI. Cross-target clippy works only for `kv-core` (`aws-lc-sys` needs a C cross toolchain); CI covers Windows.

## Review Focus

1. **Agent-controlled text with terminal escape sequences** (a client name or URL containing `ESC ]52` or `ESC [2J`) must be drawn inert, in the approvals list and in the audit tab. Pinned by `agent_supplied_text_is_made_safe_for_the_terminal` (Task 2) and `control_characters_in_the_log_are_made_safe` (Task 5).
2. **A TUI left open overnight** must not keep the vault unlocked: polling is not use. Pinned by `the_idle_lock_ends_sessions_and_polling_does_not_count_as_use` (Task 1).
3. **Locking while an agent waits** must answer it at once and never run it afterwards, and old grants must not survive an unlock. Pinned by `locking_answers_a_waiting_request_at_once` and `locking_drops_waiting_requests_and_grants` (Task 2).
4. **Replacing the token of a `base_url` handle** without retyping the hidden address must keep the address. Pinned by `an_http_value_without_a_base_url_keeps_the_one_the_handle_has` (Task 4).
5. **A secret pasted into the TUI** (a token, a database URL, or a variable value pasted before its name) must never be drawn. Pinned by `a_new_http_handle_never_shows_its_token`, `a_new_postgres_handle_takes_a_url` and `a_value_pasted_before_its_name_is_not_shown` (Task 4).

Why it looks like this:
- A token is 32 random bytes as 64 hex characters, compared in constant time, held in `SecretText` so it never shows in `Debug` output. At most 16 are open; the oldest is dropped.
- The token is accepted instead of the passphrase for every command except `Init`, `OpenSession` and `ChangePassphrase`. `OpenSession` unlocks a locked vault.
- `lock_vault()` clears the sessions, so `kv lock`, `kv stop`, the idle lock and a passphrase change all end them. Unlocking again with the passphrase does not bring old tokens back.
- A wrong token is `session_ended` and does not count toward the passphrase backoff.
- `Overview` returns before the audit write and does not touch the idle timer, so a TUI left open never keeps the vault unlocked.

Why it looks like this:
- The decision happens under the daemon lock; the wait does not. `prepare_in` returns `Prepared::Wait`, and the server waits on the receiver outside the lock with `timeout(wait, ..)`. On timeout it calls `expire`; if that returns `None` a decision arrived in the same instant, so it takes it with `try_recv`.
- Locking drops every pending sender, so a waiting request is answered `vault_locked` at once and never runs later; grants are cleared too. Each dropped request is audited with decision `locked`.
- `AllowSession` grants (session id, handle) until the handle's `grant_ttl`, and only for a request that named a session (`can_grant`). Exec asks only for the handles in `mode: ask`; a grant covers each separately.
- `DenyAlways` sets every asking handle to `mode: deny`.
- At most 32 requests wait at once; the 33rd is refused with `approval_timeout` and says so.
- Agent-supplied text (client name, URL, argv, cwd) passes through `printable()`: control characters become U+FFFD and text is cut (client 64 characters, detail and cwd 300), because the TUI draws it.
- The `Hello` frame is optional and gets no reply; ids over 128 bytes or clients over 1024 bytes are `bad_request`. `kv mcp` sends one per connection with a random 16-byte session id and the MCP client's `clientInfo.name`.
- `kv status` and the MCP `status` tool report how many requests are waiting.

+//! Unlocking trades the passphrase for a session token held only in this
+//! process; every later request uses the token.
+
+pub mod app;
+pub mod view;

+use std::time::Duration;

+use kv_core::secret::SecretText;
+use ratatui::DefaultTerminal;
+use ratatui::crossterm::event::{self, Event, KeyEventKind};

+use crate::paths::Paths;

+/// How often the screen asks the daemon for news.
+const REFRESH: Duration = Duration::from_millis(500);
+
+/// Carries out effects against the daemon and holds the session token.
+pub struct Driver {
+    paths: Paths,
+    token: Option<SecretText>,
+}
+
+impl Driver {
+    pub fn new(paths: Paths) -> Self {
+        Self { paths, token: None }
+    }
+
+    pub async fn run(&mut self, effect: Effect) -> Outcome {
+        match effect {
+            Effect::OpenSession(passphrase) => {
+                let request = ControlRequest {
+                    passphrase: Some(passphrase),
+                    token: None,
+                    command: ControlCommand::OpenSession,
+                };
+                match client::control(&self.paths, &request, true).await {
+                    Ok(ControlResponse::Session { token }) => {
+                        self.token = Some(token);
+                        Outcome::Opened
+                    }
+                    Ok(ControlResponse::Error { message, .. }) => Outcome::Failed(message),
+                    Ok(other) => Outcome::Failed(format!("unexpected reply: {other:?}")),
+                    Err(e) => Outcome::Failed(format!("could not reach the kv daemon: {e}")),
+                }
+            }
+            Effect::Decide { id, verdict } => {
+                self.send(ControlCommand::Decide { id, verdict }).await
+            }
+            Effect::Lock => {
+                self.token = None;
+                let request = ControlRequest {
+                    passphrase: None,
+                    token: None,
+                    command: ControlCommand::Lock,
+                };
+                match client::control_if_running(&self.paths, &request).await {
+                    Ok(None | Some(ControlResponse::Done { .. })) => Outcome::Done(Vec::new()),
+                    Ok(Some(other)) => Outcome::Failed(format!("could not lock: {other:?}")),
+                    Err(e) => Outcome::Failed(format!("could not lock: {e}")),
+                }
+            }
+            Effect::Quit => Outcome::Done(Vec::new()),
+        }
+    }
+
+    /// Fetches what the screen shows. `None` without a session.
+    pub async fn refresh(&mut self) -> Option<Outcome> {
+        self.token.as_ref()?;
+        Some(self.send(ControlCommand::Overview).await)
+    }
+
+    async fn send(&mut self, command: ControlCommand) -> Outcome {
+        let Some(token) = self.token.clone() else {
+            return Outcome::Ended("unlock first".into());
+        };
+        let request = ControlRequest {
+            passphrase: None,
+            token: Some(token),
+            command,
+        };
+        match client::control_if_running(&self.paths, &request).await {
+            Ok(Some(ControlResponse::Overview { overview })) => Outcome::Overview(overview),
+            Ok(Some(ControlResponse::Done { warnings })) => Outcome::Done(warnings),
+            Ok(Some(ControlResponse::Error {
+                code: ControlErrorCode::SessionEnded,
+                message,
+            })) => {
+                self.token = None;
+                Outcome::Ended(message)
+            }
+            Ok(Some(ControlResponse::Error { message, .. })) => Outcome::Failed(message),
+            Ok(Some(other)) => Outcome::Failed(format!("unexpected reply: {other:?}")),
+            Ok(None) | Err(_) => {
+                self.token = None;
+                Outcome::Ended("the kv daemon stopped; unlock again".into())
+            }
+        }
+    }
+}

+/// Runs the terminal UI until the user quits.
+pub async fn run(paths: Paths) -> io::Result<()> {
+    if !io::stdin().is_terminal() || !io::stdout().is_terminal() {
+        return Err(io::Error::other("kv tui needs a terminal"));
+    }
+    let mut terminal = ratatui::init();
+    let result = event_loop(&mut terminal, paths).await;
+    ratatui::restore();
+    result
+}
+
+async fn event_loop(terminal: &mut DefaultTerminal, paths: Paths) -> io::Result<()> {
+    let (keys_tx, mut keys) = tokio::sync::mpsc::unbounded_channel();
+    // crossterm's reader blocks, so it gets a thread of its own.
+    std::thread::spawn(move || {
+        while let Ok(event) = event::read() {
+            if let Event::Key(key) = event
+                && key.kind == KeyEventKind::Press
+                && keys_tx.send(key).is_err()
+            {
+                break;
+            }
+        }
+    });
+    let mut app = App::new();
+    let mut driver = Driver::new(paths);
+    let mut tick = tokio::time::interval(REFRESH);
+    loop {
+        terminal.draw(|frame| view::draw(frame, &app))?;
+        tokio::select! {
+            key = keys.recv() => {
+                let Some(key) = key else { return Ok(()) };
+                let Some(effect) = app.handle_key(key) else { continue };
+                if effect == Effect::Quit {
+                    return Ok(());
+                }
+                let outcome = driver.run(effect).await;
+                app.apply(outcome);
+                if let Some(outcome) = driver.refresh().await {
+                    app.apply(outcome);
+                }
+            }
+            _ = tick.tick() => {
+                if let Some(outcome) = driver.refresh().await {
+                    app.apply(outcome);
+                }
+            }
+        }
+    }
+}

+    pub fn passphrase_len(&self) -> usize {

+    /// The waiting request the decision keys act on.
+    pub fn selected(&self) -> usize {
+        self.selected

+    pub fn handle_key(&mut self, key: KeyEvent) -> Option<Effect> {
+        if key.modifiers.contains(KeyModifiers::CONTROL) && key.code == KeyCode::Char('c') {
+            return Some(Effect::Quit);
+        }
+        match self.screen {
+            Screen::Unlock => self.unlock_key(key),
+            Screen::Main => self.main_key(key),
+        }
+    }
+
+    pub fn apply(&mut self, outcome: Outcome) {
+        match outcome {
+            Outcome::Opened => {
+                self.screen = Screen::Main;
+                self.tab = Tab::Approvals;
+                self.message = None;
+            }
+            Outcome::Overview(overview) => {
+                let waiting = overview.approvals.len();
+                self.selected = self.selected.min(waiting.saturating_sub(1));
+                self.overview = Some(overview);
+            }
+            Outcome::Ended(reason) => {
+                self.screen = Screen::Unlock;
+                self.overview = None;
+                self.message = Some(reason);
+            }
+            Outcome::Failed(message) => self.message = Some(message),
+            Outcome::Done(warnings) => {
+                self.message = (!warnings.is_empty()).then(|| warnings.join("; "));
+            }
+        }
+    }
+
+    fn unlock_key(&mut self, key: KeyEvent) -> Option<Effect> {
+        match key.code {
+            KeyCode::Char(c) => self.passphrase.push(c),
+            KeyCode::Backspace => {
+                self.passphrase.pop();
+            }
+            KeyCode::Enter => {
+                let passphrase = SecretText::new(self.passphrase.as_str());
+                self.passphrase.clear();
+                self.message = Some("unlocking…".into());
+                return Some(Effect::OpenSession(passphrase));
+            }
+            KeyCode::Esc => return Some(Effect::Quit),
+            _ => {}
+        }
+        None
+    }
+
+    fn main_key(&mut self, key: KeyEvent) -> Option<Effect> {
+        match key.code {
+            KeyCode::Char('q') | KeyCode::Esc => return Some(Effect::Quit),
+            KeyCode::Char('L') => {
+                self.screen = Screen::Unlock;
+                self.overview = None;
+                self.message = Some("locked".into());
+                return Some(Effect::Lock);
+            }
+            KeyCode::Char('1') => self.tab = Tab::Approvals,
+            KeyCode::Char('2') => self.tab = Tab::Handles,
+            KeyCode::Tab => {
+                self.tab = match self.tab {
+                    Tab::Approvals => Tab::Handles,
+                    Tab::Handles => Tab::Approvals,
+                }
+            }
+            _ if self.tab == Tab::Approvals => return self.approvals_key(key),
+            _ => {}
+        }
+        None
+    }
+
+    fn approvals_key(&mut self, key: KeyEvent) -> Option<Effect> {
+        let waiting = self.overview.as_ref().map_or(0, |o| o.approvals.len());
+        let verdict = match key.code {
+            KeyCode::Up | KeyCode::Char('k') => {
+                self.selected = self.selected.saturating_sub(1);
+                return None;
+            }
+            KeyCode::Down | KeyCode::Char('j') => {
+                self.selected = (self.selected + 1).min(waiting.saturating_sub(1));
+                return None;
+            }
+            KeyCode::Char('a') => Verdict::AllowOnce,
+            KeyCode::Char('s') => Verdict::AllowSession,
+            KeyCode::Char('d') => Verdict::Deny,
+            KeyCode::Char('D') => Verdict::DenyAlways,
+            _ => return None,
+        };
+        let approval = self.overview.as_ref()?.approvals.get(self.selected)?;
+        if verdict == Verdict::AllowSession && !approval.can_grant {
+            self.message = Some(
+                "this request did not name its agent session, so it can only be allowed once"
+                    .into(),
+            );
+            return None;
+        }
+        Some(Effect::Decide {
+            id: approval.id,
+            verdict,
+        })
+    }

Why it looks like this:
- `App` is a pure state machine, so every key and every reply is tested without a terminal; `view` only reads it, and is tested by drawing into a `TestBackend`.
- The passphrase lives in a `Zeroizing<String>`, is drawn as dots and is cleared as soon as Enter sends it.
- `Driver` maps `session_ended`, a stopped daemon and a failed connection to `Ended`, which drops the token and returns to the unlock screen.
- The terminal loop uses `ratatui::init()` / `ratatui::restore()`; crossterm's blocking `event::read` runs on its own thread and feeds a channel, and the screen refreshes every 500 ms and after each effect. `kv tui` refuses to start without a terminal.

Why it looks like this:
- `Update` keeps the policy and creation time. The value must be the same kind; changing kind means remove and add. An http value without `base_url` keeps the handle's base URL, because the TUI never learns it and a user replacing a token should not silently lose the address it hides.

- Secret fields are drawn as dots. In the variables field only names show, and only once `=` is typed, so a value pasted first is never drawn; Enter adds `NAME=value`, Backspace on an empty input drops the last one.
- The edit form prefills what `HandleInfo` reveals (description, where the token goes) and leaves secrets blank; blank keeps them. Moving the token or setting a base URL needs the token again.
- The policy form shows the fields that apply to the kind and sends only what changed; methods are upper-cased.
- A failed save keeps the form open with the daemon's message; `Done` closes it. Removing asks for `y`.

+/// The last `max` entries of the log, newest first. Reads only the end of
+/// the file; a missing log has no entries, and lines that do not parse are
+/// skipped. Control characters are replaced, so the text is safe to draw.
+pub fn tail(path: &Path, max: usize) -> io::Result<Vec<Entry>> {
+    let mut file = match File::open(path) {
+        Ok(file) => file,
+        Err(e) if e.kind() == io::ErrorKind::NotFound => return Ok(Vec::new()),
+        Err(e) => return Err(e),
+    };
+    let start = file.metadata()?.len().saturating_sub(TAIL_BYTES);
+    file.seek(SeekFrom::Start(start))?;
+    let mut bytes = Vec::new();
+    file.read_to_end(&mut bytes)?;
+    let text = String::from_utf8_lossy(&bytes);
+    let mut lines = text.lines();
+    if start > 0 {
+        // The first line is most likely cut off.
+        lines.next();
+    }
+    Ok(lines
+        .rev()
+        .filter_map(|line| serde_json::from_str::<Entry>(line).ok())
+        .map(Entry::made_safe)
+        .take(max)
+        .collect())
