# kv Plan 7: `kv tray` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A menu bar icon (macOS) and notification area icon (Windows) that shows whether the vault is locked and how many agent requests wait, and answers them from its menu after a Touch ID or Windows Hello unlock.

**Architecture:** `kv tray` is a subcommand of the `kv` binary. A pure `tray::model` turns the daemon's `Status` and `Overview` into the icon state, tooltip and menu, with every item's id naming its action (`decide:<request id>:<verdict>`). A `tray::worker` on a background tokio runtime reads the status every second without starting the daemon, holds the session through the TUI's `Driver`, and carries out clicks. `tray::ui` owns the main thread (tao event loop plus tray-icon), rebuilds the menu when a new model arrives, and sends clicks to the worker. `tray::login` writes the login item. The daemon gains nothing new except that agent status reads no longer keep a locked daemon running.

**Tech Stack:** Rust 2024 (MSRV rises to 1.90), tray-icon 0.26 (muda 0.21 as `tray_icon::menu`), tao 0.37, windows-sys 0.61 (`Win32_System_Registry`), notify-rust 4.

**Spec:** `docs/superpowers/specs/2026-10-12-kv-tray-design.md`; the main design `docs/superpowers/specs/2026-10-08-kv-llm-secrets-broker-design.md` stays the authority for sessions, approvals and device unlock. Task 6 writes the decisions below into both.

## Decisions this plan makes

Each is a choice for you to confirm or change.

- **Agent status reads no longer keep a locked daemon running.** The spec promises that a tray left running does not keep a daemon alive, but every agent request, `Status` included, reset the timer behind the locked exit (10 minutes). Task 1 exempts `AgentRequest::Status`, as it already did not count toward the idle lock, and changes the existing `locked_daemon_exits_after_a_quiet_period` test to use `ListHandles`. Agents that only ever poll the status no longer keep a locked daemon up either.
- **`kv tray --login on|off` changes the login item, prints what it did and exits.** It does not also start a tray.
- **"Open kv tui" on Windows is `cmd /c start "" <exe> tui`** (cmd itself with `CREATE_NO_WINDOW`), not a search for `wt.exe` as the spec said: `start` opens the user's default terminal, which is Windows Terminal when they chose it. On macOS it is `osascript` telling Terminal to `do script` the shell-quoted path.
- **Windows console.** `kv.exe` is a console program, so the Run key starts it with a console window. The tray frees a console that no other process shares; a brief flash at login remains. Started from a terminal it keeps that console.
- **No vault yet:** the menu reads "No vault yet: run `kv init`" and "Open kv tui" instead of the unlock item.
- **Countdowns update in place.** The menu is replaced only when its items change (`same_shape`); when only "Expires in Ns" lines change, their text is set on the existing items, so an open menu is not swapped every second.
- **Notifications** have the title "kv tray" and carry the daemon's or device's message with its first letter capitalised, so the spec's "That request is no longer waiting" reads "That request is no longer waiting for approval".
- **Icons:** a key drawn at 32×32 in code; emerald while unlocked, grey at 60% opacity while locked or off, plus a red badge (Windows only) while requests wait. On macOS it is a template image and the count is the title beside it.
- **Platforms per module:** `model`, `worker`, `icon` and `login` build everywhere, so their tests run in all three CI jobs; `ui` and the tao/tray-icon dependencies are macOS and Windows only. CI's `msrv` job runs on Linux, so it moves to 1.90 but does not compile the tray crates.
- **The login checkbox** shows whether the item exists, not whether it points at the running `kv`.

## Global Constraints

- Every cargo command runs with `export DEVELOPER_DIR=/Library/Developer/CommandLineTools` set (this Mac's linker). The live database tests are unaffected by this plan and skip without `KV_TEST_POSTGRES_URL` / `KV_TEST_REDIS_URL`.
- Rust 1.90 is the minimum supported version (`rust-version` in `Cargo.toml`).
- No new daemon commands: the tray uses `Status` (agent socket, no session), `OpenSession`, `Overview`, `Decide` and `Lock`, as `kv tui` does.
- The tray never asks for or accepts the passphrase; it unlocks only through the `Device` path, whose key goes only to a daemon running the same program.
- Every decision names a request id, never a position in the menu.
- Status reads in the tray never start the daemon; only Unlock does.
- `tao` and `tray-icon` are dependencies for `cfg(any(target_os = "macos", windows))` only; `kv tray` elsewhere fails with "kv tray runs on macOS and Windows only".
- Copy, verbatim: tooltips "kv: not running", "kv: no vault yet", "kv: locked", "kv: unlocked", "kv: N requests waiting" ("kv: 1 request waiting"); menu items "Unlock with Touch ID" / "Unlock with Windows Hello", "Unlock in kv tui", "Open kv tui", "Start at login", "Quit kv tray", "Lock vault", "No requests waiting", "N handle requests: open kv tui", "Allow once", "Allow for this session", "Deny", "Deny and block <handles>", "Expires in Ns"; the prompt reason "open kv tray, where you approve agent requests"; "kv tray is already running".
- Commits as DFanso <leogavin123@outlook.com>, no AI attribution.
- `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings` and `cargo test --workspace` stay clean after every task. Windows-only code is compiled and tested by CI's windows-latest job: kv cannot be cross-checked from macOS because aws-lc-sys does not cross-compile.

## Review Focus

None of these can run in CI or in this plan's tests; each is a manual check before release (Task 5, Step 6).

- A menu left open while the worker ticks: on macOS and Windows the "Expires in Ns" line counts down without the menu closing, and when a request arrives or is answered elsewhere the menu changes without a click landing on a different request (a click on a request that has gone shows the "no longer waiting" notification).
- The Touch ID sheet from the tray, which has no window and no Dock icon: it appears in front, names "open kv tray, where you approve agent requests", and Cancel shows a notification instead of nothing.
- Notifications from a tray started by the LaunchAgent rather than a terminal: they show on macOS (notify-rust from an unbundled binary) and as toasts on Windows.
- Windows start-up from the Run key: only a brief console flash, then the icon; "Open kv tui" opens a console running `kv tui`; the Hello dialog comes to the front.
- The icon on light and dark backgrounds: the template key in both macOS menu bar styles with the count beside it; the grey and emerald key and the red badge on light and dark Windows taskbars.

+/// What a click asks for.

+    Unlock,

+/// `text` on one line of at most `max` characters: control characters and
+/// line breaks become spaces, runs of whitespace collapse, and a longer
+/// text ends in "…".
+pub fn one_line(text: &str, max: usize) -> String {
+    let words: Vec<&str> = text
+        .split(|c: char| c.is_whitespace() || c.is_control())
+        .filter(|word| !word.is_empty())
+        .collect();
+    let line = words.join(" ");
+    if line.chars().count() <= max {
+        return line;
+    }
+    let mut cut: String = line.chars().take(max.saturating_sub(1)).collect();
+    cut.push('…');
+    cut
+}

+/// a request's countdown. Then the tray changes those lines in place rather

+    a.len() == b.len()

+                    items: a_items,
+                },
+                Item::Submenu {
+                    id: b_id,
+                    label: b_label,
+                    items: b_items,
+                },
+            ) => a_id == b_id && a_label == b_label && same_shape(a_items, b_items),
+            (a, b) => a == b,
+        })

+//! daemon's status every second, holds the session, and carries out what

+    fn notify(&self, text: &str);
+    /// Opens a terminal running `kv tui`.
+    fn open_tui(&self) -> io::Result<()>;
+    fn login_is_on(&self) -> bool;

+impl<D: Desktop> Worker<D> {
+    pub fn new(paths: Paths, device: Option<Arc<dyn Device>>, desktop: D) -> Self {
+        Self {
+            driver: Driver::with_device(paths.clone(), device).with_reason(REASON),
+            paths,
+            desktop,
+        }
+    }
+
+    /// What the tray should show now. Reading the status never starts the
+    /// daemon; a session the daemon no longer knows is dropped.
+    pub async fn model(&mut self) -> Model {
+        let status = match client::agent_if_running(&self.paths, &AgentRequest::Status).await {
+            Ok(Some(AgentResponse::Status { status })) => Some(status),
+            _ => None,
+        };
+        let overview = match self.driver.refresh().await {
+            Some(Outcome::Overview(overview)) => Some(overview),
+            _ => None,
+        };
+        Model::new(View {
+            status: status.as_ref(),
+            overview: overview.as_ref(),
+            device: self.driver.device(),
+            login: self.desktop.login_is_on(),
+        })
+    }
+
+    /// Carries out one click. Returns true for Quit.
+    pub async fn act(&mut self, action: Action) -> bool {
+        match action {
+            Action::Unlock => {
+                let answer = self.driver.ask_device().await;
+                self.unlock(answer).await;
+            }
+            Action::Decide { id, verdict } => {
+                let outcome = self.driver.run(Effect::Decide { id, verdict }).await;
+                self.report(outcome);
+            }
+            Action::Lock => {
+                let outcome = self.driver.run(Effect::Lock).await;
+                self.report(outcome);
+            }
+            Action::OpenTui | Action::HandleRequests => {
+                if let Err(e) = self.desktop.open_tui() {
+                    self.desktop.notify(&format!("Could not open kv tui: {e}"));
+                }
+            }
+            Action::Login(on) => {
+                if let Err(e) = self.desktop.set_login(on) {
+                    self.desktop
+                        .notify(&format!("Could not change the login item: {e}"));
+                }
+            }
+            Action::Quit => return true,
+        }
+        false
+    }

+    /// the UI drops its sender. A Touch ID prompt runs beside the loop, so
+    /// the icon stays current while the user decides.
+    pub async fn run(
+        mut self,
+        mut actions: UnboundedReceiver<Action>,
+        mut show: impl FnMut(Model),
+    ) {
+        let mut tick = tokio::time::interval(TICK);
+        let mut prompt = None;
+        loop {
+            tokio::select! {
+                answer = async { prompt.as_mut().expect("guarded").await }, if prompt.is_some() => {
+                    prompt = None;
+                    self.unlock(answer).await;
+                }
+                action = actions.recv() => match action {
+                    None | Some(Action::Quit) => return,
+                    Some(Action::Unlock) => {
+                        prompt.get_or_insert_with(|| self.driver.ask_device());
+                        continue;
+                    }
+                    Some(action) => {
+                        self.act(action).await;
+                    }
+                },
+                _ = tick.tick() => {}
+            }
+            show(self.model().await);
+        }
+    }
+
+    async fn unlock(&mut self, answer: DeviceAnswer) {
+        let outcome = self.driver.finish_device(answer).await;
+        self.report(outcome);
+    }
+
+    fn report(&self, outcome: Outcome) {
+        if let Outcome::Failed(message) | Outcome::Ended(message) = outcome {
+            self.desktop.notify(&sentence(&message));
+        }
+    }
+}

+/// The daemon's messages start in lower case, to follow other text; a
+/// notification shows one on its own.
+fn sentence(message: &str) -> String {
+    let mut chars = message.chars();
+    match chars.next() {
+        Some(first) => first.to_uppercase().chain(chars).collect(),
+        None => String::new(),
+    }
+}

+//! The tray's icon, drawn in code so the binary carries no image files: a
+//! key, dimmed while locked, with a badge while requests wait. macOS draws
+//! it as a template image (alpha only), so it follows the menu bar; there
+//! the waiting count is the title beside the icon instead of the badge.
+
+use super::model::IconState;
+
+/// Width and height in pixels.
+pub const SIZE: u32 = 32;
+
+const ON: [u8; 3] = [0x10, 0xb9, 0x81];
+const OFF: [u8; 3] = [0x80, 0x80, 0x80];
+/// How opaque the key is while locked.
+const OFF_ALPHA: f32 = 0.6;
+const BADGE: [u8; 3] = [0xef, 0x44, 0x44];
+
+/// The icon for `state`, as RGBA rows of `SIZE` pixels.
+pub fn rgba(state: IconState) -> Vec<u8> {
+    let (color, alpha) = match state {
+        IconState::Off | IconState::Locked => (OFF, OFF_ALPHA),
+        IconState::Unlocked | IconState::Waiting(_) => (ON, 1.0),
+    };
+    let badged = matches!(state, IconState::Waiting(_));
+    let mut image = Vec::with_capacity((SIZE * SIZE * 4) as usize);
+    for y in 0..SIZE {
+        for x in 0..SIZE {
+            let key = coverage(x, y, in_key) * alpha;
+            let badge = if badged {
+                coverage(x, y, in_badge)
+            } else {
+                0.0
+            };
+            // The badge over the key.
+            let total = badge + key * (1.0 - badge);
+            let channel = |i: usize| {
+                if total == 0.0 {
+                    0
+                } else {
+                    let mixed = BADGE[i] as f32 * badge + color[i] as f32 * key * (1.0 - badge);
+                    (mixed / total).round() as u8
+                }
+            };
+            image.extend([
+                channel(0),
+                channel(1),
+                channel(2),
+                (total * 255.0).round() as u8,
+            ]);
+        }
+    }
+    image
+}
+
+/// How much of pixel (x, y) lies inside the shape, from 16 samples.
+fn coverage(x: u32, y: u32, inside: fn(f32, f32) -> bool) -> f32 {
+    let mut hits = 0;
+    for i in 0..4 {
+        for j in 0..4 {
+            let sx = x as f32 + (i as f32 + 0.5) / 4.0;
+            let sy = y as f32 + (j as f32 + 0.5) / 4.0;
+            if inside(sx, sy) {
+                hits += 1;
+            }
+        }
+    }
+    hits as f32 / 16.0
+}

+/// A key lying on its side: a ring on the left, the shaft to the right,
+/// two teeth below it.
+fn in_key(x: f32, y: f32) -> bool {
+    let ring = ((x - 9.5).powi(2) + (y - 16.0).powi(2)).sqrt();
+    let rect = |left: f32, top: f32, right: f32, bottom: f32| {
+        (left..right).contains(&x) && (top..bottom).contains(&y)
+    };
+    (3.0..7.0).contains(&ring)
+        || rect(15.5, 14.5, 29.0, 17.5)
+        || rect(21.5, 17.5, 24.0, 22.0)
+        || rect(26.5, 17.5, 29.0, 20.5)
+}

+    (x - cx).powi(2) + (y - cy).powi(2) < 36.0

+/// Runs the event loop; returns only if it cannot start.
+pub fn run(paths: Paths, lock: File) -> io::Result<()> {
+    #[cfg(windows)]
+    leave_own_console();
+    let runtime = tokio::runtime::Builder::new_current_thread()
+        .enable_all()
+        .build()?;
+    #[allow(unused_mut)]
+    let mut event_loop = EventLoopBuilder::<Message>::with_user_event().build();
+    #[cfg(target_os = "macos")]
+    {
+        use tao::platform::macos::{ActivationPolicy, EventLoopExtMacOS};
+        // A menu bar item only: no Dock icon, no app menu.
+        event_loop.set_activation_policy(ActivationPolicy::Accessory);
+    }
+
+    let (actions, inbox) = tokio::sync::mpsc::unbounded_channel();
+    MenuEvent::set_event_handler(Some(move |event: MenuEvent| {
+        if let Some(action) = Action::from_id(event.id.as_ref()) {
+            let _ = actions.send(action);
+        }
+    }));
+    let proxy = event_loop.create_proxy();
+    std::thread::spawn(move || {
+        let worker = Worker::new(paths, device::platform().map(Arc::from), System);
+        let show = proxy.clone();
+        runtime.block_on(worker.run(inbox, move |model| {
+            let _ = show.send_event(Message::Show(model));
+        }));
+        let _ = proxy.send_event(Message::Quit);
+    });
+
+    let mut tray: Option<Tray> = None;
+    event_loop.run(move |event, _, flow| {
+        // Held for as long as the loop runs.
+        let _ = &lock;
+        *flow = ControlFlow::Wait;
+        match event {
+            Event::NewEvents(StartCause::Init) => match Tray::new() {
+                Ok(created) => tray = Some(created),
+                Err(e) => {
+                    eprintln!("kv: cannot show the tray icon: {e}");
+                    *flow = ControlFlow::ExitWithCode(1);
+                }
+            },
+            Event::UserEvent(Message::Show(model)) => {
+                if let Some(tray) = &mut tray {
+                    tray.show(model);
+                }
+            }
+            Event::UserEvent(Message::Quit) => {
+                tray = None;
+                *flow = ControlFlow::Exit;
+            }
+            _ => {}
+        }
+    })
